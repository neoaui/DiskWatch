# 简洁分层界面（2026-11-14）

## 参考

- DaisyDisk 官方概览：https://daisydiskapp.com/guide/4/en/DisksOverview/ 。借鉴先看磁盘与剩余容量的入口。
- DaisyDisk 官方层级导航：https://daisydiskapp.com/guide/4/en/UnderstandingSunburst/ 。借鉴逐层展开与小项收纳，不复制其图形资产。
- TreeSize 官方概览：https://manuals.jam-software.com/treesize/EN/overview.html 。参考目录层级与历史视图分离。
- WizTree 官方：https://diskanalyzer.com/ 。参考大小排序定位占用来源。本轮采用适合当前快照粒度的分类/目录层级，不声称提供完整逐文件树。

## 最终交互

- 四个侧栏入口：空间总览、变化趋势、历史报表、设置。
- 首屏为磁盘卡片（剩余容量、占用条、低空间提示），点击磁盘只显示该盘的扫描摘要。
- 摘要下的分类、大文件、覆盖、更多统计默认收起；同层展开时收起其他项。
- 分类 → 目录 → 已记录的大文件逐层展开。目录首次展开才加载，每次显示 20 项；子项明确是大文件记录而非完整文件清单。
- 常用主操作为“开始扫描”；旁边是扫描范围下拉（默认“全部磁盘”，可改选当前在线的某一个盘）；取消按钮仅在扫描期间出现，此时范围下拉不可改。选目录、刷新、暂停、保存完整总结和退出收在更多菜单。
- 设置按扫描计划、空间提醒、分类纠正分组，默认收起；历史页将提醒历史折叠。
- 浅灰背景、白色卡片、青色强调、统一圆角与低饱和曲线配色；保留原生窗口与键盘焦点提示。
