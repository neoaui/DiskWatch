# 安全安装（可选）

默认情况下，从仓库编译并运行即可：数据目录位于仓库根目录，或由环境变量 `DISKWATCH_ROOT` 指定。

若希望程序文件对普通用户只读，可以把发布结果放到一个受保护的安装目录，并用附带的安全启动器启动。源码中的示例路径是 `C:\Program Files\DiskWatch`，可在 `src\SecureLaunchPolicy.cs` 中修改。

建议的布局：

- 安装目录：仅系统和管理员可写入，已认证用户可读取和执行。其中包含独立运行时（`runtime\`）、应用程序（`app\DiskWatch.App.dll`）和安全启动器。
- 数据目录：放在用户可写入的位置，例如 `%LOCALAPPDATA%\DiskWatch`。安全启动器会把 `DISKWATCH_ROOT` 指向该目录，用于保存数据库、设置、日志和导出文件。

安全启动器只在自身位于上述安装目录时才会运行，以避免尚未审查的暂存包被直接提权执行。部署时请自行设置目录所有者和访问控制，不要把本机用户 SID 或开发路径写进仓库。

本仓库不包含针对特定计算机的 ACL 脚本。
